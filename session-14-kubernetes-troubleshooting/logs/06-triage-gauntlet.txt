# ROOT CAUSE: the process allocates ~1GB while the limit is 20Mi. The kernel's

# Memory is INCOMPRESSIBLE: exceeding a CPU limit only throttles, but exceeding
# a memory limit kills the container outright.

# without understanding the allocation just delays the same failure.
