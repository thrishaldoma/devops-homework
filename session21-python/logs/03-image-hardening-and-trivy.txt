# Explaining the backend finding, which is what M6 asks for: all three HIGH
# entries are the same package - starlette 0.41.3, pulled in transitively
# by the pinned fastapi==0.115.6. CVE-2025-62727 is a denial of service via

# which is exactly why --ignore-unfixed does not hide them: that flag only
