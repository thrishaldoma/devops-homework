# ===== ArgoCD refused to sync, and it was RIGHT to =====
$ kubectl get application -n argocd session20-mini -o jsonpath='{.status.conditions[0].message}{"\n"}'
Failed to load target state: failed to generate manifest for source 1 of 1: rpc error: code = Unknown desc = repository contains out-of-bounds symlinks. file: 01-linux/links-lab/broken

# This is a supply-chain control, not a bug. An out-of-bounds symlink in a Git
# repo can point at anything on the repo-server's filesystem - /etc/passwd, a
# mounted token - and ArgoCD would happily render it into a manifest. So the
# repo-server refuses the whole repository.
# 
# The offending file is from Session 1's links lab:
$ ls -la 01-linux/links-lab/broken
lrwxr-xr-x@ 1 thrishaldoma  staff  12 Sep  4 22:41 01-linux/links-lab/broken -> /nonexistent

$ grep -n 'ln -s /nonexistent broken' 01-linux/README.md | head -2
187:$ ln -s /nonexistent broken && find . -xtype l

# It is a deliberately broken symlink, documented with captured output in
# Session 1. Rewriting it would make that evidence inconsistent with its own
# artifact, so it stays.
# 
# ===== resolution =====
# ArgoCD exposes an escape hatch, marked '(not recommended)':
$ kubectl exec -n argocd deploy/argocd-repo-server -c argocd-repo-server -- argocd-repo-server --help 2>&1 | grep -A1 'allow-oob-symlinks'
      --allow-oob-symlinks                             Allow out-of-bounds symlinks in repositories (not recommended)
      --client-ca-path string                          Path to the client CA certificate file for mTLS. Defaults to the auto-mounted Secret path; mTLS is skipped if the file does not exist. (default "/app/config/reposerver/mtls/client-ca.crt")

# Enabling it is defensible HERE and nowhere else: this is a single-author
# homework monorepo, the symlink is known, benign and documented, and the
# repo is public so there is nothing on the repo-server worth exfiltrating.
# 
# THE PRODUCTION ANSWER IS DIFFERENT: keep a SEPARATE config repository
# containing only manifests. That is standard GitOps practice for reasons
# beyond this symlink - a small config repo means a tighter RBAC surface, a
# clean audit trail of deploys, and application commits that do not trigger
# reconciliation. The monorepo here is a homework constraint, not a model.
$ kubectl set env deployment/argocd-repo-server -n argocd ARGOCD_REPO_SERVER_ALLOW_OUT_OF_BOUNDS_SYMLINKS=true
deployment.apps/argocd-repo-server env updated
