# Not a flaw in either run. requirements.txt pins only Flask==3.1.3; Flask
# depends on click>=8.1.3, so the version is resolved at install time. My
# machine had click 8.1.8 cached (vulnerable, PYSEC-2026-2132); the CI runner
# resolved click 8.5.0 (patched).
# LESSON: without a lockfile, an SCA scan describes the machine it ran on, not
# the application. Two engineers get two answers, and so does prod. The fix is
# a fully-pinned lockfile (pip-compile / Pipfile.lock / poetry.lock) so the
# resolved tree is identical everywhere and the scan result is reproducible.
